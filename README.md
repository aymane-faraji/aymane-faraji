## 💻 Bioinformatics Projects

### **Transcriptomic Reanalysis of MSCs Cultured with FBS vs Human Platelet Lysate**
* **Data & Tools:** Reanalyzed a public dataset (GEO GSE194298) of 16 samples using R and limma.
* **Methodology:** Accounted for culture condition and cell passage, identifying 1,608 differentially expressed genes with FDR correction.
* **Findings:** Interpreted GO and KEGG pathways related to extracellular-matrix organization, wound healing, and cytokine signaling.

### **RNA-seq Analysis of Escherichia coli WT versus ΔslyA**
* **Workflow:** Built an end-to-end bacterial RNA-seq pipeline using FastQC, MultiQC, fastp, HISAT2, samtools, featureCounts, and DESeq2.
* **Metrics:** Achieved 96–98% alignment rates and generated gene-level count matrices.
* **Findings:** Identified ~319 differentially expressed genes to interpret bacterial regulation context.

### **SARS-CoV-2 Viral Genomics Analysis**
* **Workflow:** Executed a reproducible viral genomics workflow using Nextflow and nf-core/viralrecon for QC, mapping, and variant calling.
* **Tools:** Called variants with iVar, annotated with SnpEff, and assigned clades using Pangolin and Nextclade.
* **Visualization:** Explored and visualized variant metrics downstream using R and ggplot2.
